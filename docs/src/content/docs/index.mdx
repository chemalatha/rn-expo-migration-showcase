## The app

**Component Showcase** (`src/ComponentShowcase.tsx`) is a single screen that puts five standalone design-system components to work together:

| Component | What it shows |
|-----------|--------------|
| `TopBar` | Platform-aware navigation bar — centred title on iOS, left-aligned on Android |
| `Heading` | Level 1 heading using `headline1` type size |
| `BodyText` | `md` size body copy, `shortForm` line height |
| `Heading` | Level 2 with `visualSize="headline4"` override |
| `Button` | Primary variant with live tap counter — proves interactivity |

The screen title is **"Component Showcase"**. The heading reads **"DDS Standalone Components"**. Tapping the button increments a counter — confirming that state, events, and re-rendering all work identically on iOS, Android, and web.

> This file is never modified across any phase of the migration. It is the proof that the component API is fully portable.

## The design system

Five components built entirely from React Native primitives — no `@ddsrn/*` packages, no `react-native-svg`, no reanimated.

<CardGrid>
  <Card title="ThemeProvider + useTheme" icon="sun">
    Tesco light tokens inlined. Same `brand` / `mode` props as dds-react-native.
  </Card>
  <Card title="Heading" icon="list-format">
    Levels 1–6 with independent `visualSize` override. `accessibilityRole="header"` everywhere.
  </Card>
  <Card title="BodyText" icon="document">
    `xs` `sm` `md` `lg` sizes. `shortForm` and `longForm` line heights.
  </Card>
  <Card title="Button" icon="approve-check-circle">
    `primary` `secondary` `tertiary` `link` variants. Inlined `useButton` accessibility logic.
  </Card>
  <Card title="TopBar" icon="bars">
    Title, left and right slots. iOS centres, Android left-aligns.
  </Card>
  <Card title="Zero external deps" icon="puzzle">
    Only `react`, `react-native`, `react-native-safe-area-context` at runtime.
  </Card>
</CardGrid>

## Migration path

The design system and screen code never change. Only build tooling changes between phases.

| Phase | Change | Screen diff |
|-------|--------|-------------|
| 1 — Bare React Native | Baseline — identical toolchain to dds-react-native Playground | — |
| 2 — Expo SDK | 5 config files | 0 lines |
| 3 — Expo Web | 3 web deps added | 0 lines |
| 4 — Screenshots + Docs | Playwright script, this Astro site | 0 lines |
